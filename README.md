# MBA Pharma Demand Dashboard

Interactive executive dashboard for the MBA capstone "Demand Forecasting and Inventory Decisions in Pharmaceutical Distribution" (Group 9230, Team 2, Data Analytics for AI Business, AASTMT).

Open the live dashboard: see the GitHub Pages link in the repository's About section.

- Single self-contained page (`index.html`): data, charts and logic are embedded; no server or login needed.
- All figures come from a fully synthetic educational dataset; they do not describe any real company, market or patient.
- Charts by Apache ECharts 5.5.1 (Apache-2.0), embedded in the page.
